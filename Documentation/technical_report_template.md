# Technical Report Template
1. Problem statement and intended users.
2. Input data/knowledge base: list actual sources, versions, licenses, permissions, and processing.
3. Architecture: include `architecture.md` diagram.
4. Implementation/configuration: explain Streamlit, deterministic ASIL, TF-IDF, optional Ollama, SQLite, Docker.
5. Evaluation: insert actual results only; distinguish unit tests from matrix verification.
6. Responsible AI: grounding, privacy, human oversight, abstention, limitations.
7. Innovation: separation of deterministic ASIL lookup from LLM drafting and traceability.
8. Limitations/future work.
9. References with versions and access dates.
10. Appendix: actual logs, screenshots, and authorized review evidence.
