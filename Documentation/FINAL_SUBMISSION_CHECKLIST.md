# Final submission checklist

This archive contains the software project and draft documentation, but a few items require student action and cannot honestly be auto-completed.

## Included
- Streamlit source and deterministic candidate ASIL lookup
- Dockerfile and Docker Compose
- Unit test source
- HARA, draft requirement, evidence search, traceability and export workflows
- Architecture and responsible-AI/security documentation
- Technical report template, demo script, and declaration templates
- Evaluation plan and blank results template

## Must be completed before submission
- [ ] Run `docker compose up --build` and verify the application in a browser.
- [ ] Run `pytest -q`; copy the actual output to the report.
- [ ] Verify the entire ASIL matrix against an approved, applicable licensed reference and document reviewer/date. Do not claim compliance based only on the included public secondary source.
- [ ] Evaluate with permitted project documents and record actual results in `Evaluation_Results/results_template.csv`.
- [ ] Complete the technical report using actual methods/results and export it to PDF.
- [ ] Record the required 5–10 minute demonstration video and place it in `Video/`.
- [ ] Complete and sign the official Academic Integrity and AI-Tool Usage declarations. Templates in this ZIP are not official forms.
- [ ] Verify citations, licenses, student details, and faculty folder naming requirements.

Do not report tests as passed unless you ran them. Do not sign any declaration until its statements are accurate.
